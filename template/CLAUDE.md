# Project instructions

Read [ESX project instructions](esx/project_instructions.md), then
[the project profile](esx/project_profile.md). The project owner supplies the
scientific objectives, invariants and authorization. Arch coordinates the work.

Write all text that a person reads in ASD-STE100 (Simplified Technical English): issues, lessons,
long-term goals, status, summaries and messages. Read `devel-loop/writing_standard.md`.

Packet assembly and recovery: `devel-loop/recovery.md` defines exact review
handoffs, read-only readiness, assessed same-session continuation and evidence reuse.
